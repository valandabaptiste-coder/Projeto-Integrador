Introdução Geral do Projeto

Este projeto articula Robótica, Tecnociência e Programação Web para desenvolver soluções tecnológicas voltadas à inclusão social de pessoas com baixa visão ou cegueira.

1. Robótica: Controle Luminoso e Síntese de Cores

Controle PWM Arduino

Simulação no Tinkercad com recurso PWM para controle gradual de iluminação (0 a 255), prevenindo a fadiga ocular.

Síntese Aditiva (LED RGB)

[ Ilustração do Circuito LED RGB ]

Manipulação dos canais Vermelho, Verde e Azul via potenciômetros para gerar combinações cromáticas e alto contraste.
